## Descripcion del taller
Este repositorio contiene 14 ejercicios de recursividad resueltos en Java
aplicando principios de Programacion Orientada a Objetos (POO). Cada ejercicio
esta en su propia clase con el metodo main correspondiente, e implementa al
menos una funcion recursiva.

Los ejercicios cubren:
 Factorial, invertir numero, sumatoria armonica
 Suma de digitos, sumatoria de enteros, potencia
 MCD con algoritmo de Euclides, copiar cadena
 Cociente y multiplicacion por restas/sumas sucesivas
 Suma de elementos de arreglo y matriz
 Serie de Fibonacci y funcion de Ackerman

## Tecnologias utilizadas
 Java JDK 21 superior al 17
 IDE recomendado: NetBeans, Visual
